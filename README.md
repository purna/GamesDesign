# Games Design learning resources

Interactive activities for games design students: creative process, research, coding, narrative and career exploration.

Links below use the current filenames in this repository. Published pages require the latest files to be deployed to GitHub Pages. Student work is saved by individual tools; use their download/backup options when moving devices.

## UAL unit documents and evidence planning

These mappings are teaching suggestions based on the supplied **UAL Level 3 Diploma and Extended Diploma in Creative Practice: Art, Design and Communication** documents. They are not a separate Games Development unit specification or a guarantee of assessment achievement. Unit 1 and Unit 2 use learning outcomes (LO) and numbered criteria; Unit 3 uses assessment outcomes (AO).

| Unit document | Relevant focus | Suggested evidence |
| --- | --- | --- |
| [Unit 1 — The Creative Process](Units/Unit%201%20-%20The%20Creative%20Process.pdf) | LO1 creative process; LO2 planning; LO3 research; LO4 intent and purpose; LO5 visual language; LO6 reflection; LO7 idea generation and ethical design. | Research records, annotated diagrams, alternative ideas, brief analysis and reflections showing how decisions changed. |
| [Unit 2 — Developing Creative Practice](Units/Unit%202%20-%20Developing%20Creative%20Practice.pdf) | LO4 problem-solving and LO6 presentation are the clearest shared links for these tools. LO1–LO3 concern 2D, 3D and 4D creative practices; LO5 concerns safe working. | Record a problem, propose and apply a solution, test it and assess the result. Present development clearly and evaluate the presentation. |
| [Unit 3 — Responding to a set brief](Units/Unit%203%20-%20Responding%20to%20a%20set%20brief.pdf) | AO1 brief requirements; AO2 planning; AO3 research; AO4 practical skills; AO5 ideas; AO6 outcomes; AO7 presentation; AO8 reflection. | Connect research and diagrams to the actual vocational brief, show implementation and refinement, and present outcomes with evaluation. The unit also requires a completed project proposal and summative evaluation. |

A diagram can support Unit 1 LO5 as visual communication. It does not, by itself, establish Unit 2 LO1 merely because it appears on a two-dimensional screen. Map practical work to Unit 2 LO1–LO3 only where the task actually explores, experiments with, assesses and refines the relevant creative practice. Safe-working evidence for Unit 2 LO5 must be planned separately.

For reflection outcomes, retain evidence of a next step being acted on, not just answers to the reflection questions. For Unit 3, adapt classroom examples to the set brief and assess the resulting portfolio holistically.
